[AK01] Finite state machines - educational tools.
The centre of this project is the design and development of educational tools dealing with finite automata, regular expressions and Turing machines. There are 5 different projects for 5 students in this topic-group:
  • (1) Animated interactive visual toolkit for finite deterministic and non-deterministic automata.
    The aim of this project is to design and develop an animated interactive visual toolkit for basic features of finite automata, such as an animated interactive visual simulator for deterministic/non-deterministic automata, and an interactive visual implementation of the Subset Construction (that turns a non-deterministic automaton to an equivalent deterministic one). The user-friendly GUI should be suitable for beginners in the area. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible.
    • (2) Animated interactive visual toolkit for pushdown automata.
    The centre of this project is the design and development of an animated interactive visual simulator for pushdown automata, together with a GUI suitable for using the simulator as an educational tool for beginners. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible. A collection of good test-examples should also be constructed.
  • (3) Implementing algorithms connecting finite automata and regular expressions.
    The aim of this project is to implement an animated interactive visual toolkit for the two algorithms connecting a finite automaton and the regular expression representing its language. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible. Creating collections of finite automata and regular expressions facilitating extensive testing would also be required.
  • (4) Implementing equivalence-testing and state minimisation algorithms.
    The aim of this project is to understand, implement and compare several algorithms that determine whether two finite automata are equivalent or not. Modifications of these algorithms should also be used turn a deterministic finite automaton to an equivalent one having a minimal number of states. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible. An important part of the project is an example-generator facilitating systematic large-input testing (kind of experimentally showing the known worst-case complexity of the various algorithms). Extensive visuals are not needed, but a friendly and informative user interface is necessary.
  • (5) Animated interactive visual toolkit for Turing machines.
    The centre of this project is the design and development of an animated interactive visual simulator for various versions of Turing Machines, together with a GUI suitable for using the simulator as an educational tool for beginners. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible. A collection of good test-examples should also be constructed.
The version numbers allocated by the system do not matter. After allocation, I'll ask your preference-list about the versions, and will try to negotiate with everybody in the team about who gets which one of (1)-(5). Of course, I'll try to accommodate everybody's wishes, but sometimes it might be necessary to choose in random. We will agree as a team, until everybody is (reasonably) happy.

[AK02] Discrete-maths tutor - educational tools.
The centre of this project is the design and development of interactive apps (for Android/iOS or web app or standalone) with loads of visuals that can assist revision of selected topics in discrete-maths modules (like FC1/FC2 and possibly beyond). The point is to develop interactive and visual functionalities for notions and algorithms (NOT to encode easy hardwired stuff like quizzes and textual background material). There are 5 different projects for 5 students in this topic-group. Here are some suggested project topics (but tools aiding other parts of discrete-maths learning can also be subject to discussion):
  • (1) Graph visualisation and algorithms.
    The aim of this project is to implement an interactive visual toolkit for representing various kinds of graphs (directed and undirected) and for teaching many important algorithms on them. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible.
  • (2) Tree visualisation and algorithms.
    The aim of this project is to implement an interactive visual toolkit for rooted trees and their algorithms, including building and manipulating n-ary trees and various traversal algorithms on them, building and searching binary search trees, and AVL-trees and operations on them. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible.
  • (3) Relations and functions tutor.
    The aim of this project is to design and develop an animated interactive visual toolkit for basic representation methods, properties and algorithms in connection with binary relations and functions. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible.
  • (4) Discrete probability tutor.
    The aim of this project is to design and develop an animated interactive visual toolkit for basic features of discrete probability, concentrating on conditional probability and practicing/demonstrating Bayes' theorem `in action' (including, for example, a visual simulation of various versions of the Monty Hall puzzle).
  • (5) Visualising approximation algorithms for the Travelling Salesman Problem.
    The aim of this project is to design and develop an interactive and visual tool for visualising and comparing several approximation algorithms for the Travelling Salesman Problem.

[AK03] Logic tutor - educational tools.
The centre of this project is the design and development of interactive apps (for Android/iOS or web app or standalone) with loads of visuals that can assist revision of selected topics in logic modules (like ELA/FC2 and possibly beyond). The point is to develop interactive and visual functionalities for notions and algorithms (NOT to encode easy hardwired stuff like quizzes and textual background material). There are 5 different projects for 5 students in this topic-group. Here are some suggested project topics (but tools aiding other parts of logic learning can also be subject to discussion):
  • (1) Propositional logic: interactive and visual educational tools.
    The aim of this project is to design and develop an animated interactive visual toolkit for basic features of propositional logic, such as interactive truth-tables and an interactive visual implementation of the Davis–Putnam–Logemann–Loveland (DPLL) satisfiability-checking algorithm. Other basic tools might also be included.
  • (2) Natural deduction - an interactive and visual educational tool.
    The aim of this project is to design and develop an interactive and visual tool for constructing and checking Natural Deduction proofs in propositional logic (and possibly beyond). The user-friendly GUI should be suitable for beginners in the area. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible.
  • (3) Visualising algorithms for Ordered Boolean Decision Diagrams (OBDDs).
    The aim of this project is to implement an interactive visual toolkit for the four basic algorithms (reduce, apply, restrict, exists) manipulating OBDDs. For more information, check here, or consult
    M. Huth and M. Ryan, Logic in Computer Science: Modelling and Reasoning about Systems. 2nd edition, Cambridge University Press, 2004. ISBN 9780521543101
  • (4) Modal logic: checking formulas in Kripke models - an interactive and visual educational tool.
    The aim of this project is to design and develop an interactive and visual tool for constructing Kripke models, and then checking modal formulas in them. The user-friendly GUI should be suitable for beginners in the area. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible. For more information, check here, or consult
    M. Huth and M. Ryan, Logic in Computer Science: Modelling and Reasoning about Systems. 2nd edition, Cambridge University Press, 2004. ISBN 9780521543101
  • (5) Modal logic: satisfiability checking with tableaux - an interactive and visual educational tool.
    The aim of this project is to design and develop an interactive and visual tool for checking the satisfiability of modal formulas using the tableaux algorithm. The user-friendly GUI should be suitable for beginners in the area. The suggested implementation language is JAVA or C++ or Python, but other high level languages would also be possible. For more information, check here, or consult
    M. Huth and M. Ryan, Logic in Computer Science: Modelling and Reasoning about Systems. 2nd edition, Cambridge University Press, 2004. ISBN 9780521543101
